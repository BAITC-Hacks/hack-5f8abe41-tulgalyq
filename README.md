# Миссия 100

Рабочий прототип платформы бизнес-задач для HackAlem AI. Бизнес вводит свободное описание, отвечает на уточняющие вопросы, редактирует и подтверждает карточку. После подтверждения она попадает в каталог, где команды могут предложить решения. Тот же адаптивный интерфейс подготовлен для запуска как Telegram Mini App.

## Запуск

Нужен Python 3.9 или новее. Внешние пакеты не требуются.

```bash
python3 app.py
```

Откройте <http://localhost:8000>. Данные сохраняются в `data/mission100.sqlite3`; эта папка не попадает в Git.

Для короткого показа жюри используйте [сценарий демо](DEMO.md).

## Что работает сейчас

- Создание черновика из свободного текста.
- Три уточняющих вопроса о недостающих данных.
- Редактируемая карточка с полями из кейса.
- Предварительный рейтинг по шкале 0–100 и подсказки о недостающих полях.
- Ручное подтверждение карточки; только после него баллы считаются начисленными.
- Сохранение карточки между перезагрузками браузера.
- Демо-кабинет бизнеса со всеми черновиками и опубликованными карточками: можно продолжить уточнение, открыть редактор или перейти к задаче в каталоге. Пока нет авторизации, это общий список записей демо-базы, а не персональные «мои задачи».
- Подробная разбивка баллов по каждому полю: видно, какие баллы уже подтверждены, какие возможны после подтверждения и что ещё пусто.
- Общий каталог только подтверждённых задач, сортировка по рейтингу/готовности и фильтры по теме и диапазону готовности. Низкий рейтинг не блокирует отклики.
- Профили команд, неограниченные предложения с идеей, планом и необязательной ссылкой на прототип.
- Фильтр откликов по задаче и статусу; из кабинета бизнеса можно сразу открыть отклики нужной миссии.
- Ручное решение бизнеса: выбрать одну или несколько команд, отклонить или не принимать решения.
- Подтверждение выполненного этапа даёт команде 10 прогресс-баллов; повторно подтвердить тот же этап нельзя. Баллы видны в таблице прогресса команд.
- Кнопка демо-данных добавляет 5 синтетических карточек с разными рейтингами, 5 черновиков, 5 команд и 5 предложений. Повторное нажатие не дублирует записи.
- По желанию бизнес может нажать «Спросить AI»: при наличии серверного `OPENAI_API_KEY` OpenAI задаст три конкретных вопроса к черновику. AI не заполняет карточку и не начисляет баллы без ответа бизнеса.

## Формула рейтинга

Контекст — 10, потребность — 10, данные — 20, ожидаемый результат — 15, критерии успеха — 15, ограничения — 10, пользователи — 10, контакт — 5, формат взаимодействия — 5. Сумма — 100. Пока поле пустое, за него начисляется 0. Изменение подтверждённой карточки требует нового подтверждения.

## Telegram Mini App

Веб-интерфейс уже подключает официальный `telegram-web-app.js`, сообщает Telegram о готовности и разворачивает окно Mini App. На узком экране появляется нижняя навигация.

Чтобы открыть приложение *в Telegram*, нужны два внешних шага:

1. Разместить этот Python-сервер по публичному HTTPS-адресу. Для локальной разработки сервер слушает только `127.0.0.1`; в доверенной среде хостинга можно задать `HOST=0.0.0.0` и `PORT`.
2. Создать бота в [@BotFather](https://t.me/BotFather), а затем задать `TELEGRAM_BOT_TOKEN` и `MINI_APP_URL=https://адрес-сайта` в окружении и запустить `python3 setup_telegram.py`. Скрипт настроит кнопку меню бота через Bot API. Токен нельзя коммитить в Git и нельзя присылать в чат.

Интерфейс не использует `initDataUnsafe` как доказательство личности. Сейчас это **демо без авторизации и разграничения ролей**: не размещайте его публично с реальными данными или реальным ботом, пока не будут добавлены проверка подписанных `initData`, роли бизнеса/команд и права на изменение своих записей. `localhost` сам по себе не откроется у других пользователей Telegram.

## Необязательная AI-функция

Задайте `OPENAI_API_KEY` в окружении процесса сервера (не в браузере и не в репозитории), затем перезапустите сервер. По умолчанию используется `gpt-4o-mini`; при необходимости модель можно заменить через `OPENAI_MODEL`. При нажатии «Спросить AI» исходное описание задачи отправляется в OpenAI Responses API. Если ключа нет, остаются три локальных вопроса по правилам. Если API недоступен, карточку всё равно можно заполнить вручную.

Учитывайте конфиденциальность: не отправляйте в AI личные или чувствительные данные в черновике. Ответ модели содержит только вопросы; факты бизнеса не придумываются и не записываются без подтверждения человека.

## Архитектура

`app.py` — HTTP API и SQLite. `static/` — интерфейс на HTML, CSS и JavaScript. `setup_telegram.py` — необязательная настройка бота. Секреты и данные не хранятся в репозитории. `python3 -m unittest -v test_app.py` проверяет сквозной сценарий.

## Ограничения прототипа

Без API-ключа уточняющие вопросы выбираются из локального набора правил. Текущий рейтинг прозрачно проверяет заполненность и ручное подтверждение полей, но не оценивает смысл текста: бессмысленный ввод может получить баллы. Для реального запуска также нужны авторизация, права доступа, защита от спама и полноценный хостинг.
