# Миссия 100

Рабочий прототип платформы бизнес-задач для HackAlem AI. Бизнес вводит свободное описание, отвечает на уточняющие вопросы, редактирует и подтверждает карточку. После подтверждения она попадает в каталог, где команды могут предложить решения. Сайт адаптирован для компьютера и телефона.

## Запуск

Нужен Python 3.9 или новее. Внешние пакеты не требуются.

```bash
python3 app.py
```

Откройте <http://localhost:8000>. Данные сохраняются в `data/mission100.sqlite3`; эта папка не попадает в Git.

Для короткого показа жюри используйте [сценарий демо](DEMO.md).

## Проверка сквозного сценария

1. В «Конструкторе» введите слабое описание задачи и ответьте на три уточняющих вопроса.
2. Заполните название и потребность, откройте карточку: справа видны предварительный рейтинг и баллы за каждое поле. Добавьте сведения, затем сохраните и подтвердите карточку.
3. В «Каталоге» найдите опубликованную задачу. По умолчанию карточки упорядочены по рейтингу; проверьте фильтры темы и четырёх уровней готовности. Даже подтверждённая задача с низким баллом принимает отклики.
4. Создайте команду с интересами, навыками и технологиями, отправьте идею, план, срок и, если есть, ссылку на прототип.
5. В «Откликах команд» выберите или отклоните предложение вручную. Для выбранной команды отправьте этап работы и подтвердите его: после этого в рейтинге команд появятся 10 баллов.

Для автоматической проверки запустите `python3 -m unittest -v test_app.py`; тесты используют временную базу и не меняют данные сайта.

## Что работает сейчас

- Создание черновика из свободного текста.
- Три уточняющих вопроса о недостающих данных.
- Редактируемая карточка с полями из кейса.
- Предварительный рейтинг по шкале 0–100 и подсказки о недостающих полях.
- Ручное подтверждение карточки; только после него баллы считаются начисленными.
- Сохранение карточки между перезагрузками браузера.
- Демо-кабинет бизнеса со всеми черновиками и опубликованными карточками: можно продолжить уточнение, открыть редактор или перейти к задаче в каталоге. Пока нет авторизации, это общий список записей демо-базы, а не персональные «мои задачи».
- Подробная разбивка баллов по каждому полю: видно, какие баллы уже подтверждены, какие возможны после подтверждения и что ещё пусто.
- Общий каталог только подтверждённых задач: по умолчанию задачи идут по убыванию рейтинга; доступны фильтры по теме и уровню готовности. Низкий рейтинг не блокирует отклики.
- Профили команд с интересами, навыками и технологиями; неограниченные предложения с идеей, планом, сроком и необязательной ссылкой на прототип.
- Фильтр откликов по задаче и статусу; из кабинета бизнеса можно сразу открыть отклики нужной миссии.
- Ручное решение бизнеса: выбрать одну или несколько команд, отклонить или не принимать решения.
- Подтверждение выполненного этапа даёт команде 10 прогресс-баллов; повторно подтвердить тот же этап нельзя. Баллы видны в таблице прогресса команд.
- Кнопка демо-данных добавляет 5 синтетических карточек с разными рейтингами, 5 черновиков, 5 команд и 5 предложений. Повторное нажатие не дублирует записи. Ссылки в демо-записях служат образцом формата, а не действующими прототипами.
- По желанию бизнес может нажать «Спросить AI»: при наличии серверного `OPENAI_API_KEY` OpenAI задаст три конкретных вопроса к черновику. AI не заполняет карточку и не начисляет баллы без ответа бизнеса.

## Формула рейтинга

Контекст — 10, потребность — 10, данные — 20, ожидаемый результат — 15, критерии успеха — 15, ограничения — 10, пользователи — 10, контакт — 5, формат взаимодействия — 5. Сумма — 100. Пока поле пустое, за него начисляется 0. Изменение подтверждённой карточки требует нового подтверждения.

Уровни из кейса: 0–39 — требует уточнения, 40–69 — рабочая, 70–89 — готовая, 90–100 — приоритетная. Низко оценённая, но подтверждённая задача остаётся в каталоге и принимает отклики; неподтверждённые черновики туда не попадают. При одинаковом рейтинге сохраняется порядок новых задач.

## Мобильный интерфейс

Это тот же сайт: на узком экране карточки перестраиваются в одну колонку и появляется нижняя навигация. Для просмотра на этом ноутбуке откройте `http://localhost:8000`. Адрес `localhost` на телефоне указывает на сам телефон, поэтому для проверки на другом устройстве понадобится отдельный доступ к серверу по локальной сети или хостинг.

Сейчас это **демо без авторизации и разграничения ролей**: не размещайте его публично с реальными данными, пока не будут добавлены роли бизнеса/команд и права на изменение своих записей.

## Необязательная AI-функция

Задайте `OPENAI_API_KEY` в окружении процесса сервера (не в браузере и не в репозитории), затем перезапустите сервер. По умолчанию используется `gpt-4o-mini`; при необходимости модель можно заменить через `OPENAI_MODEL`. При нажатии «Спросить AI» исходное описание задачи отправляется в OpenAI Responses API. Если ключа нет, остаются три локальных вопроса по правилам. Если API недоступен, карточку всё равно можно заполнить вручную.

Промпт просит ровно три разных вопроса на русском, каждый привязан к незаполненному полю, без выдумывания фактов. Вход — исходное описание бизнеса; выход — JSON-объект с массивом `questions`, где каждый элемент содержит `field` (например, `users`) и `text` (например, «Кто будет пользоваться решением?»). Сервер проверяет количество, уникальность полей и длину вопросов; некорректный ответ отклоняется, исходная карточка не меняется.

Учитывайте конфиденциальность: не отправляйте в AI личные или чувствительные данные в черновике. Ответ модели содержит только вопросы; факты бизнеса не придумываются и не записываются без подтверждения человека.

## Архитектура

`app.py` — HTTP API и SQLite; при запуске старые демо-базы дополняются новыми полями без удаления записей. `static/` — интерфейс на HTML, CSS и JavaScript. Секреты и данные не хранятся в репозитории. `python3 -m unittest -v test_app.py` проверяет сквозной сценарий.

## Ограничения прототипа

Без API-ключа уточняющие вопросы выбираются из локального набора правил. Текущий рейтинг прозрачно проверяет заполненность и ручное подтверждение полей, но не оценивает смысл текста: бессмысленный ввод может получить баллы. Для реального запуска также нужны авторизация, права доступа, защита от спама и полноценный хостинг.
