# Tulgalyq — описание для жюри

Актуальная версия для оценки находится в ветке `Moldiyar`.

## Одним предложением

Tulgalyq превращает расплывчатый запрос бизнеса в проверяемую студенческую миссию: AI помогает уточнить описание, бизнес подтверждает факты, а открытый рейтинг показывает, насколько задача готова к работе.

## Проблема и решение

Команде трудно откликаться на задачу, когда неизвестны данные, ожидаемый результат или критерии успеха. Привычный рейтинг компании этого не решает. Мы оцениваем не компанию и не студентов, а **готовность одной конкретной задачи** по шкале 0–100 из кейса. Пустоты видны всем, но даже карточка с низким баллом остаётся в каталоге и принимает предложения.

Бизнес вводит идею свободным текстом. Gemini предлагает три уточняющих вопроса, не добавляя фактов в карточку. Бизнес дополняет поля и вручную подтверждает публикацию; до этого рейтинг остаётся предварительным. Команды видят подтверждённую версию, отправляют идею и план, а бизнес самостоятельно выбирает одну, несколько или ни одной команды. Прогресс команды получает баллы только после подтверждения этапа.

## Что отличает проект

1. **Рейтинг-навигатор, а не витрина популярности.** Видно, за какие сведения начислены баллы и что уточнить для следующего уровня готовности.
2. **Паспорт миссии.** Из опубликованной карточки скачивается бриф с подтверждёнными сведениями, рейтингом и открытыми вопросами. Несогласованные правки не попадают в файл или каталог.
3. **AI под контролем человека.** Модель задаёт вопросы, но не придумывает материалы, сроки и показатели, не публикует карточку и не выбирает исполнителя. Если API недоступен, интерфейс честно показывает локальный режим.

## Как показать за три минуты

Используйте [сценарий демо](DEMO.md): слабая задача в каталоге → повышение готовности после подтверждения → скачивание паспорта → предложение команды → ручной выбор → баллы за подтверждённый этап → живые AI-вопросы и мобильный интерфейс.

## Запуск и проверка

Из корня репозитория: `python3 app.py`, затем откройте `http://127.0.0.1:8000/`. Нажмите «Попробовать на примере», затем «Продолжить», чтобы увидеть вопросы без подготовки данных. Требуется только Python 3.9+, внешних библиотек нет. Автотесты: `python3 -m unittest -q test_app.py`. Ключ Gemini задаётся в локальном `.env` по образцу `.env.example`; без него платформа сохраняет основной сценарий на локальных вопросах. Секреты и база SQLite исключены из Git.

Полная [сверка с требованиями кейса](CASE_CHECKLIST.md) отделяет реализованный MVP от ограничений: это демо без авторизации и публичного хостинга, не готовый сервис для реальных персональных данных.
